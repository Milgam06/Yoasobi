# YOASOBI 🌙

> 이번 주엔 언제 걸을까요?

금요일 새벽에 20분쯤 걸어볼까요? 아직 거리가 조용한 시간에 집 앞을 한 바퀴 돌아오는 거예요. 이번 주에 그런 시간을 한 번쯤 만들어보고 싶다면, Yoasobi에서 산책 일정을 정해보세요.

Yoasobi는 **일주일에 한 번, 나만의 새벽 산책을 계획하는 앱**이에요. 걷고 싶은 요일이 있다면 직접 고르고, 어느 날로 할지 고민된다면 뽑기에 맡겨보세요. 요일을 정한 뒤에는 몇 시에 출발할지, 얼마나 걸을지 고르면 돼요. 정해둔 일정은 홈에서 다시 확인할 수 있어요.

멀리 갈 필요는 없어요. 익숙한 동네라도 평소와 다른 시간에 걸어보면 조금 다르게 느껴질지도 몰라요.

## 이번 주 새벽 산책 정하기

1. 산책할 요일을 직접 고르거나 무작위로 뽑아요.
2. 몇 시에 출발할지, 얼마나 걸을지 정해요.
3. 홈에서 이번 주 산책 일정을 확인해요.
